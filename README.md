# raulcardenasmontoya.me

A static Astro + TypeScript portfolio for AI/ML systems engineering. It deploys to GitHub Pages at `raulcardenasmontoya.me` from `main`. The repository is named `rmems/raulcardenasmontoya.me` to match the canonical domain; earlier names are retired.

## Local development

```bash
npm install
npm run dev
```

Then open the local URL Astro prints (normally `http://localhost:4321`).

## Checks

```bash
npm run validate
```

The validation command runs content/route contracts, linting, Astro type checks, a production build, the locked Rust/WASM adapter checks, and a headless-Chrome layout check (every built page at 320–1024 px with 100% and 200% text, in the site's fonts and in a wide fallback face, must not scroll horizontally). Before running it locally, install Rust 1.99.0 with the `wasm32-unknown-unknown` target, `wasm-bindgen-cli 0.2.126`, and a local Chrome or Chromium executable. Supply absolute executable paths for the browser smoke check:

```bash
WASM_BINDGEN_BIN="$(command -v wasm-bindgen)" BROWSER_BIN="$(command -v google-chrome)" npm run validate
```

The browser-loadable adapter packages committed at `public/wasm/neuromorphic-adapter/` (homepage) and `public/wasm/neuromorphic-adapter-labs/` (off-homepage labs, built with extra cargo features; profiles in `scripts/wasm-profiles.mjs`) are generated output — deterministic under the locked toolchain. Regenerate both after changing the crate or its dependencies with `WASM_BINDGEN_BIN="$(command -v wasm-bindgen)" npm run build:wasm-web`; `npm run test:wasm-web-pkg` (part of `validate`) fails on drift.

Pull requests provision these dependencies and run the same command in CI. The **Deploy** workflow (`.github/workflows/deploy.yml`) repeats the validation on pushes to `main` and then publishes `dist` to GitHub Pages.

Coverage and Qlty uploads run in the **Quality** workflow (`coverage report and
uploads` job, in parallel with `validate`). See
[docs/coverage-and-quality.md](docs/coverage-and-quality.md) for local coverage,
Codecov/Qlty setup, and fork-PR behavior.

## Content and assets

- Site-wide identity, social URL placeholders, email placeholder, and résumé path: `src/data/site.ts`
- Project cards and work-page briefs: `src/data/projects.ts`
- Dated snapshots behind every count on the site (crates.io and Hugging Face, with collections): `src/data/artifacts/`, refreshed with `node scripts/build-crates-snapshot.mjs` and `node scripts/build-hf-snapshot.mjs`; `src/artifacts/counts.ts` is the only place pages read counts from
- Markdown notes: `src/content/notes/`
- Publishing checklist: `CONTENT.md`
- Browser renderer, Rust/WASM boundary, compatibility policy, and crate audit: `docs/architecture/browser-runtime.md`
- Labs index entries: `src/data/labs.ts`; NIR example assets (`public/nir/`) and their regeneration: the NIR section of `docs/architecture/browser-runtime.md`
- Reward-modulated learning lab (`/labs/plasticity/`) golden session: `src/data/plasticity/scripted-session.v1.json`, generated by `crates/neuromorphic-adapter/tests/plasticity_session.rs` (see the lab section of `docs/architecture/browser-runtime.md`)
- Native CUDA/FPGA evidence schema and ingest: `docs/architecture/native-evidence.md`
- Recorded `corpus-ipc` protocol fixtures (`/protocol/`): `public/protocol/fixtures/v1/`, generated by `crates/neuromorphic-adapter/tests/protocol_fixtures.rs`
- Fonts: `public/fonts/` holds the self-hosted, Latin-subset Inter (upright and italic) and Newsreader italic woff2 files with their SIL OFL licences; `src/styles/global.css` declares them and the dark-scheme tokens
- Favicon: `public/favicon.svg`
- Social card (1200×630, regenerate with `node scripts/build-social-card.mjs`): `public/assets/social-card.png`

## GitHub Pages

`.github/workflows/deploy.yml` runs on every push to `main`: `npm ci`, `npm run validate`, `npm run build` (Astro, output `dist`), then `actions/upload-pages-artifact` and `actions/deploy-pages` (`pages: write`, `id-token: write`, `github-pages` environment). `npm run build` needs only Node 20.19+ or 22.12+ because the browser WASM packages are committed under `public/wasm/`; the Rust toolchain is installed only for `validate`.

One-time repository settings: Settings → Pages → Source: **GitHub Actions**; Settings → Pages → Custom domain: `raulcardenasmontoya.me` (save it; `public/CNAME` alone does not set this for Actions publishing); once DNS resolves and the certificate is issued, turn on **Enforce HTTPS**. `public/CNAME` keeps the custom domain pinned in the built site. Manual runs only deploy from `main`.
